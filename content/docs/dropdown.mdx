---
title: Dropdown
description: Present a list of selectable values.
icon: ListFilter
---

```luau
local Dropdown = Tab:Dropdown({
    Title = "Select a mode",
    Values = { "Balanced", "Performance", "Quality" },
    Value = "Balanced",
    Callback = function(value)
        print("Selected:", value)
    end,
})
```

Keep the values concise and provide a sensible initial selection when one is appropriate. Use a `Flag` if the selection should participate in config persistence.
