---
title: Notifications
description: Send concise status messages to the user.
icon: Bell
---

Use `ForktUI:Notify()` for a notification:

```luau
ForktUI:Notify({
    Title = "Settings saved",
    Content = "Your changes have been saved.",
})
```

You can move the notification stack with:

```luau
ForktUI:SetNotificationLower(true)
```

Notifications should communicate one status or action at a time. Avoid using them for long-form instructions.
