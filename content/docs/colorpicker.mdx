---
title: Color picker
description: Allow users to choose a color value.
icon: Pipette
---

```luau
local Picker = Tab:Colorpicker({
    Title = "Accent color",
    Default = Color3.fromRGB(150, 160, 175),
    Callback = function(color)
        print("Color:", color)
    end,
})
```

Use a neutral initial color when the selected color is not the main focus of the interface. The callback receives the updated color value.
