---
title: Keybind
description: Let users assign a keyboard or mouse shortcut.
icon: Keyboard
---

```luau
local Keybind = Tab:Keybind({
    Title = "Toggle interface",
    Value = "RightShift",
    CanChange = true,
    Blacklist = { "Escape" },
    Callback = function(value)
        print("Shortcut pressed:", value)
    end,
})

Keybind:Set("F")
Keybind:Lock()
Keybind:Unlock()
```

`Value` can be an `Enum.KeyCode` or its name as a string. Mouse shortcuts use `MouseButton1` and `MouseButton2`. Add disallowed keyboard or mouse names to `Blacklist`. Avoid assigning a key already required by the experience.
