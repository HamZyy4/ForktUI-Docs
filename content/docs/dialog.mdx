---
title: Dialog
description: Present a focused prompt with optional actions.
icon: MessageSquare
---

Create a dialog from a window. The dialog opens when it is created:

```luau
local Dialog = Window:Dialog({
    Title = "Discard changes?",
    Content = "Your unsaved changes will not be kept.",
    Width = 340,
    Buttons = {
        {
            Title = "Cancel",
            Variant = "Tertiary",
            Callback = function()
                print("Cancelled")
            end,
        },
        {
            Title = "Discard",
            Variant = "Primary",
            Callback = function()
                print("Discarded")
            end,
        },
    },
})
```

Each button supports `Title`, `Icon`, `Callback`, and `Variant`. Keep the message short and make the action labels unambiguous. The dialog component is created by `Window:Dialog()` in `src/components/window/Init.lua`.
