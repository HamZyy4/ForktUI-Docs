---
title: Slider
description: Let users choose a number within a range.
icon: SlidersHorizontal
---

```luau
local Slider = Tab:Slider({
    Title = "Volume",
    Step = 1,
    Value = {
        Min = 0,
        Max = 100,
        Default = 50,
    },
    Callback = function(value)
        print("Volume:", value)
    end,
})
```

Choose a range and step that fit the setting. Use a callback to update the related value when the slider changes.
