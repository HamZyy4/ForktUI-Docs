## Get the config manager

```luau
local ConfigManager = Window.ConfigManager
local config = ConfigManager:CreateConfig("profile")
```

## Register elements

Set a `Flag` on supported elements, or register an element manually:

```luau
local Toggle = Tab:Toggle({
    Title = "Enable option",
    Flag = "EnableOption",
    Callback = function(value)
        print(value)
    end,
})

config:Register("EnableOption", Toggle)
```

## Save and load

```luau
config:Save()
config:Load()
config:Delete()

local files = ConfigManager:AllConfigs()
```

Config persistence depends on the runtime's supported file APIs and the configured folder. Verify those capabilities in the environment where the UI is running.
