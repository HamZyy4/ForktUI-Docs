ForktUI is a themeable UI library for Roblox projects, built around a compact Luau API. Create a window, add tabs, then compose controls and content elements inside each tab.

## What is included

- **Window system** — resizable layouts, sidebar navigation, topbar actions, and open-button configuration.
- **Interface elements** — buttons, toggles, dropdowns, inputs, sliders, color pickers, keybinds, and more.
- **Theme support** — built-in themes, custom palettes, gradient values, and theme tags.
- **Developer utilities** — notifications, dialogs, popups, localization, and configuration persistence.
- **Icon packs** — named icons from the companion ForktUI Icons repository.

## Start here

1. Follow the [installation guide](/docs/installation) for a source or Rojo workflow.

## Minimal example

```luau
local ForktUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/HamZyy4/ForktUI/main/dist/main.lua"
))()

local Window = ForktUI:CreateWindow({
    Title = "My Hub",
    Theme = "Dark",
})

local Tab = Window:Tab({
    Title = "General",
})

Tab:Button({
    Title = "Say hello",
    Callback = function()
        print("Hello from ForktUI")
    end,
})
```
