ForktUI is a modular Luau interface toolkit for Roblox client experiences. Build a window, organize navigation with tabs and sections, then compose controls and content components inside each view.

## Library capabilities

- **Window and navigation:** a resizable window shell, sidebar, topbar actions, search control, and optional floating open button.
- **User profile card:** a clickable sidebar account card with a Roblox profile summary and anonymous display mode.
- **Controls:** buttons, toggles, dropdowns, text inputs, sliders, color pickers, and keybinds.
- **Content and layout:** paragraphs, code blocks, images, viewports, progress bars, sections, groups, horizontal stacks, and vertical stacks.
- **Feedback and overlays:** dialogs, popups, notifications, and tooltips.
- **Customization:** themes, gradients, icon packs, localization, and optional config persistence.

## Start with the loader

```luau
local ForktUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/HamZyy4/ForktUI/main/dist/main.lua"
))()

local Window = ForktUI:CreateWindow({
    Title = "My Interface",
    Author = "sukitovone",
    Theme = "Dark",
    User = { Enabled = true },
})

local MainTab = Window:Tab({ Title = "General" })
MainTab:Button({
    Title = "Say hello",
    Callback = function()
        print("Hello from ForktUI")
    end,
})
```

The remote loader requires a client runtime that supports `loadstring` and HTTP retrieval. For a standard Roblox Studio project, use the [installation guide](/docs/installation) and its ModuleScript workflow.
