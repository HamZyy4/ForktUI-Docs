---
title: Tab sections
description: Create expandable groups of controls inside a tab.
icon: Rows3
---

`Section` is an element that can contain other elements and expand or collapse:

```luau
local Section = Tab:Section({
    Title = "Movement",
    Desc = "Movement-related options",
    Opened = true,
    Box = true,
})

Section:Toggle({
    Title = "Enable movement option",
    Default = false,
    Callback = function(value)
        print(value)
    end,
})
```

A section accepts `Title`, `Desc`, `Icon`, `Opened`, `Box`, and `BoxBorder` among its configuration fields. Use sections to group related settings rather than wrapping every single control.
