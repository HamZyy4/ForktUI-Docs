---
title: Toggle
description: Let users enable or disable a setting.
icon: ToggleRight
---

```luau
local Toggle = Tab:Toggle({
    Title = "Enable feature",
    Desc = "Turn the option on or off.",
    Default = false,
    Callback = function(value)
        print("Toggle state:", value)
    end,
})
```

Use `Default` to define the initial state and `Callback` to respond to changes. Set a `Flag` when the value should be registered with the window's config manager.
