---
title: Input
description: Collect text or numeric values from the user.
icon: TextCursorInput
---

```luau
local Input = Tab:Input({
    Title = "Display name",
    Desc = "Enter a short name.",
    Value = "Player",
    Placeholder = "Type here...",
    Type = "Input",
    Callback = function(value)
        print("Input:", value)
    end,
})
```

Use `Placeholder` to explain the expected input. Validate values inside the callback before using them in other systems.
