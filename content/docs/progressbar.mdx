---
title: Progress bar
description: Display determinate or indeterminate progress.
icon: ChartNoAxesColumnIncreasing
---

## Determinate progress

```luau
local Progress = Tab:ProgressBar({
    Title = "Download progress",
    Value = {
        Min = 0,
        Max = 100,
        Default = 25,
    },
})

Progress:Set(60)
print(Progress:Get())
print(Progress:GetPercentage())
```

## Indeterminate progress

```luau
Tab:ProgressBar({
    Title = "Connecting",
    Indeterminate = true,
})
```

The determinate variant maps a value into the configured range. Values passed to `Set()` are clamped to that range.
