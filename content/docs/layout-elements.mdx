ForktUI includes layout-oriented elements for structuring content inside tabs:

- `Group` — groups related child elements.
- `HStack` — arranges content horizontally.
- `VStack` — arranges content vertically.
- `Image` — displays an image asset or supported icon.
- `Viewport` — hosts a 3D viewport component.

The repository also contains a `Video` element module; its registration is currently commented out in the element registry. Treat it as unavailable through the standard `Tab` API unless that registration is enabled in your own build.

Check the element modules under `src/elements/` for the exact fields accepted by each layout element.
