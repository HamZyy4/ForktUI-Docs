---
title: Popup
description: Display contextual information in a compact popup.
icon: PanelTop
---

Use `ForktUI:Popup()` for a popup that is not attached to a tab:

```luau
ForktUI:Popup({
    Title = "Quick information",
    Content = "Your settings have been saved.",
    Icon = "check-circle",
})
```

Buttons are optional. Add them when the popup needs an explicit action:

```luau
ForktUI:Popup({
    Title = "Confirm action",
    Content = "Continue with this change?",
    Buttons = {
        {
            Title = "Cancel",
            Variant = "Tertiary",
            Callback = function()
                print("Cancelled")
            end,
        },
        {
            Title = "Continue",
            Variant = "Primary",
            Callback = function()
                print("Confirmed")
            end,
        },
    },
})
```

The popup also accepts `Thumbnail` image data. Review `src/components/popup/Init.lua` for the full configuration handled by the current source version.
