## Create a window

`CreateWindow()` creates the main client interface. A single ForktUI instance manages one active window at a time.

```luau
local Window = ForktUI:CreateWindow({
    Title = "My Interface",
    Author = "sukitovone",
    Icon = "layout-dashboard",
    Folder = "MyInterface",
    Theme = "Dark",
    Size = UDim2.fromOffset(640, 460),
    ToggleKey = Enum.KeyCode.RightShift,
    Resizable = true,
    AutoScale = true,
    User = {
        Enabled = true,
        Anonymous = false,
    },
})
```

## Window options

| Option | Type | Default / behavior |
| --- | --- | --- |
| `Title` | `string` | Window title. Defaults to `ForktUI`. |
| `Author` | `string` | Small attribution below the title. Defaults to `sukitovone`. |
| `Icon` | `string` | Named icon or supported image reference. |
| `IconSize` | `number` | Window icon size. |
| `Folder` | `string` | Directory name used by optional config persistence. |
| `Theme` | `string` | Built-in or registered theme name. Falls back to `Dark` for an unknown name. |
| `Size` | `UDim2` | Initial size. Defaults to 720 × 520 pixels before UI scaling. |
| `MinSize` / `MaxSize` | `Vector2` | Resize bounds. Defaults to 540 × 360 and 960 × 680. |
| `Resizable` | `boolean` | Enables the resize handle. Defaults to `true`. |
| `AutoScale` | `boolean` | Fits the interface to the current viewport and re-evaluates when the viewport changes. Defaults to `true`. |
| `ToggleKey` | `Enum.KeyCode` | Keyboard shortcut for toggling the window. |
| `SideBarWidth` | `number` | Sidebar width in pixels. Defaults to 184. |
| `HideSearchBar` | `boolean` | Hides the sidebar search control when `true`. |
| `ScrollBarEnabled` | `boolean` | Enables the custom sidebar scroll indicator. |
| `Transparent` | `boolean` | Enables the transparent window appearance. |
| `Acrylic` | `boolean` | Enables the optional acrylic background effect. |
| `NewElements` | `boolean` | Uses the refreshed element spacing. Defaults to `true`; set `false` for the legacy compact layout. |
| `HidePanelBackground` | `boolean` | Hides the content panel surface. |
| `OpenButton` | `table` | Optional mobile floating open button configuration. |
| `User` | `table` | Optional account card configuration; see [User profile card](/docs/user-profile). |

## Window actions

```luau
Window:Open()
Window:Close()
Window:Toggle()
Window:Destroy()
Window:SetToggleKey(Enum.KeyCode.H)
Window:SetTitle("Updated title")
Window:SetAuthor("sukitovone")
Window:SetBackgroundImage("rbxassetid://123456789")
Window:SetBackgroundImageTransparency(0.4)
Window:SetPanelBackground(true)
Window:SetUIScale(0.9)
Window:SetToTheCenter()
```

`Window:Destroy()` closes the interface and disconnects library-owned signals. `ForktUI:GetWindowSize()` returns the current `UDim2` window size, or `nil` before a window is created.

## User card

The optional sidebar account card is enabled with `User.Enabled = true`. Clicking it opens the local Roblox account summary. It displays a headshot, display name, username, user ID, account age, and profile URL. Set `Anonymous = true` to mask the identity shown by the card.

```luau
local Window = ForktUI:CreateWindow({
    Title = "My Interface",
    User = {
        Enabled = true,
        Anonymous = false,
        Callback = function(player)
            print("Account card selected:", player.Name)
        end,
    },
})
```

`Callback` is optional. The default profile popup remains available when a callback is supplied. The callback receives the local `Player` object, or `nil` while anonymous mode is enabled.

## Open button

```luau
Window:EditOpenButton({
    Title = "Open interface",
    Icon = "panel-top",
    Enabled = true,
    Draggable = true,
    OnlyMobile = false,
})
```

## Topbar actions

```luau
Window:DisableTopbarButtons({ "Close", "Minimize" })

Window:CreateTopbarButton("Help", "circle-help", function()
    print("Help selected")
end, 900)
```
