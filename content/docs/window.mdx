## Create a window

```luau
local Window = ForktUI:CreateWindow({
    Title = "My Hub",
    Icon = "layout-dashboard",
    Author = "sukitovone",
    Folder = "MyHub",

    Size = UDim2.fromOffset(580, 460),
    MinSize = Vector2.new(560, 350),
    MaxSize = Vector2.new(850, 560),
    ToggleKey = Enum.KeyCode.RightShift,
    Theme = "Dark",
    Transparent = true,
    Resizable = true,
    SideBarWidth = 200,
    HideSearchBar = false,
    ScrollBarEnabled = true,
})
```

## Common options

| Option | Type | Purpose |
| --- | --- | --- |
| `Title` | `string` | Window title. |
| `Icon` | `string` | Named icon or supported image reference. |
| `Author` | `string` | Small author label in the title area. Defaults to `sukitovone`. |
| `Folder` | `string` | Folder name used by supported persistence features. |
| `Size` | `UDim2` | Initial window size. |
| `MinSize` / `MaxSize` | `Vector2` | Resize bounds. |
| `ToggleKey` | `Enum.KeyCode` | Key used to toggle the window. |
| `Theme` | `string` | Name of the theme to apply. |
| `Transparent` | `boolean` | Enables the transparent window style. |
| `Resizable` | `boolean` | Allows the user to resize the window. |
| `SideBarWidth` | `number` | Sidebar width. |
| `HideSearchBar` | `boolean` | Hides the search control. |
| `ScrollBarEnabled` | `boolean` | Controls the sidebar scrollbar. |
| `NewElements` | `boolean` | Uses the refreshed control spacing and layout; enabled by default. Set `false` to use the legacy compact element layout. |

## Window actions

```luau
Window:Open()
Window:Close()
Window:Toggle()
Window:SetToggleKey(Enum.KeyCode.H)
Window:SetBackgroundImage("rbxassetid://123456789")
Window:SetBackgroundImageTransparency(0.4)
Window:IsResizable(false)
Window:SetTitle("Updated title")
Window:SetAuthor("sukitovone")
```

`NewElements` is enabled by default in ForktUI and selects the refreshed control layout. Set `NewElements = false` to opt into the older compact element spacing. `ForktUI:GetWindowSize()` returns the active window's `UDim2` size, or `nil` before a window is created.

## Open button

```luau
Window:EditOpenButton({
    Title = "Open interface",
    Icon = "panel-top",
    Enabled = true,
    Draggable = true,
    OnlyMobile = false,
})
```

## Topbar buttons

```luau
Window:DisableTopbarButtons({ "Close", "Minimize" })
Window:CreateTopbarButton("Help", "circle-help", function()
    print("Help clicked")
end, 900)
```
