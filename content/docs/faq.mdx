## The icon is blank

Confirm that the `Icons` submodule is initialized with `git submodule update --init --recursive` and that the requested name exists in the selected pack. The default family is Lucide; use a prefix such as `solar:` when selecting another pack. Standard Rojo deployments do not need a separate server bridge.

## The window does not appear

Create the interface from a client context and check the Roblox output for runtime errors. Confirm that `CreateWindow()` receives a valid configuration table and that the selected theme exists.

## Configs are not saved

Config persistence uses file APIs provided by the runtime. These APIs are not available in every execution environment, so saving may be unavailable even when the UI itself works.

## Where can I report a bug?

Open an issue in the [ForktUI repository](https://github.com/HamZyy4/ForktUI). Include the Roblox environment, the exact component configuration, and the error message with secrets or private identifiers removed.
