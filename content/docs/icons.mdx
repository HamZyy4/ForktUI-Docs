ForktUI's companion icon repository contains these packs:

- Lucide
- Solar
- Craft
- Geist
- SF Symbols
- Gravity UI

## Use a named icon

```luau
local Window = ForktUI:CreateWindow({
    Title = "My Hub",
    Icon = "layout-dashboard",
})

local Tab = Window:Tab({
    Title = "General",
    Icon = "lucide:house",
})
```

A namespace prefix can select a specific pack, for example `solar:home` or `geist:window`.

## Add custom icons

```luau
ForktUI.Creator.AddIcons("custom", {
    dashboard = 1234567890,
})

local Tab = Window:Tab({
    Title = "Custom",
    Icon = "custom:dashboard",
})
```

The `Icons` repository is included as the `src/Icons` submodule. In a normal Rojo project, ForktUI requires the icon pack ModuleScripts locally and needs no additional server script or RemoteFunction. Executor-based loading retrieves the companion pack modules from the repository raw files and requires a runtime that supports HTTP requests and `loadstring`.

Icon pack source: [HamZyy4/Icons](https://github.com/HamZyy4/Icons). The original icon families remain subject to their own licenses and attribution requirements.
