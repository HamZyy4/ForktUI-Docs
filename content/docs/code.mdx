---
title: Code block
description: Display copyable code or text inside a tab.
icon: Code
---

```luau
local Code = Tab:Code({
    Title = "Example source",
    Code = [[
local message = "Hello from ForktUI"
print(message)
]],
    CodeSize = 16,
    CanCopied = true,
    OnCopy = function()
        print("Code copied")
    end,
})

Code:SetCode('print("Updated source")')
```

`CanCopied` controls the copy action and defaults to enabled. `OnCopy` is called after the copy handler runs. `SetCode()` replaces the displayed source text.
