## Get the source

Clone the library repository and initialize its companion icon submodule:

```bash
git clone --recurse-submodules https://github.com/HamZyy4/ForktUI.git
cd ForktUI
git submodule update --init --recursive
```

The `Icons` submodule provides the local icon pack ModuleScripts used by ForktUI.

## Rojo workflow

The project mapping exposes the library under `ReplicatedStorage.ForktUI`. Build or serve the project with your normal Rojo workflow, then require the `Init` ModuleScript from a client-side LocalScript:

```luau
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ForktUI = require(ReplicatedStorage:WaitForChild("ForktUI"):WaitForChild("Init"))
```

The companion icon submodule is required locally by the library. A standard Rojo deployment needs no additional server-side icon bridge.

## Build the distributable

The repository uses Aftman to install Rojo, DarkLua, and Lune. The build script generates `build/package.lua` from `package.json` and writes the bundled library to `dist/main.lua`.

```bash
npm install
aftman install
npm run build
```

See [Load ForktUI](/docs/load-forktui) for the raw loader example.
