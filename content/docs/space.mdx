---
title: Space
description: Add consistent spacing between elements.
icon: Space
---

`Space` uses `Columns` to determine the number of spacing units. The element is horizontal in regular tab content and adapts to the layout direction in groups and horizontal stacks.

```luau
Tab:Space({
    Columns = 2,
})
```

Use one spacer with an intentional size rather than stacking several empty elements.
