---
title: Localization
description: Translate text registered with localization keys.
icon: Languages
---

Create a localization table with a stable key prefix and a translation dictionary for each language:

```luau
ForktUI:Localization({
    Enabled = true,
    Prefix = "loc:",
    DefaultLanguage = "en",
    Translations = {
        en = {
            welcome = "Welcome",
        },
        id = {
            welcome = "Selamat datang",
        },
    },
})

ForktUI:SetLanguage("id")
```

Use the configured prefix at the start of UI text to bind it to a translation key:

```luau
Tab:Paragraph({
    Title = "loc:welcome",
})
```

The key after the prefix must match the key in the language dictionaries. When a selected language has no entry, ForktUI falls back to the English entry; if that is also missing, the key is shown in brackets.
