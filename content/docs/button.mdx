---
title: Button
description: Trigger an action when the user presses a control.
icon: MousePointerClick
---

## Basic button

```luau
local Button = Tab:Button({
    Title = "Run action",
    Desc = "Execute the selected operation.",
    Locked = false,
    Callback = function()
        print("Button pressed")
    end,
})
```

## Layout and color

```luau
Tab:Button({
    Title = "Centered action",
    Color = Color3.fromHex("#a1a1aa"),
    Justify = "Center", -- Center, Between, Left, or Right
    IconAlign = "Left", -- Left or Right
    Callback = function()
        print("Clicked")
    end,
})
```

## Update or remove a button

```luau
Button:SetTitle("Updated title")
Button:SetDesc("Updated description")
Button:Lock()
Button:Unlock()
Button:Destroy()
```
