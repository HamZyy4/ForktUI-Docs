## Apply a theme

```luau
ForktUI:SetTheme("Dark")
```

You can retrieve the available themes and the active theme name:

```luau
local themes = ForktUI:GetThemes()
local currentTheme = ForktUI:GetCurrentTheme()
```

## Create a custom theme

```luau
ForktUI:AddTheme({
    Name = "Graphite",
    Accent = Color3.fromHex("#202329"),
    Background = Color3.fromHex("#101216"),
    Outline = Color3.fromHex("#3a3f48"),
    Text = Color3.fromHex("#f0f1f3"),
    Placeholder = Color3.fromHex("#858b95"),
    Button = Color3.fromHex("#303640"),
    Icon = Color3.fromHex("#c2c7cf"),
})

ForktUI:SetTheme("Graphite")
```

## Theme gradients

`ForktUI:Gradient()` accepts percentage keys from `0` to `100`. Each stop requires a `Color3` value; a hex color string is also accepted.

```luau
local accent = ForktUI:Gradient({
    ["0"] = { Color = Color3.fromHex("#343941"), Transparency = 0 },
    ["100"] = { Color = Color3.fromHex("#171a20"), Transparency = 0 },
}, {
    Rotation = 0,
})

ForktUI:AddTheme({
    Name = "Graphite Gradient",
    Accent = accent,
})
```

## Theme change callback

```luau
ForktUI:OnThemeChange(function(themeName)
    print("Theme changed to", themeName)
end)
```
