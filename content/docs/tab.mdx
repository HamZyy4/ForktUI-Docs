## Create a tab

```luau
local MainTab = Window:Tab({
    Title = "General",
    Icon = "house",
    Desc = "Common settings",
})
```

Tabs can include a title, description, icon, and locked state. Use a short title so the navigation remains easy to scan, especially on narrow screens.

## Add elements

```luau
MainTab:Button({
    Title = "Example action",
    Callback = function()
        print("Action triggered")
    end,
})

MainTab:Toggle({
    Title = "Enable feature",
    Default = false,
    Callback = function(value)
        print("Enabled:", value)
    end,
})
```

Each tab exposes element methods such as `Button`, `Toggle`, `Dropdown`, `Input`, `Slider`, `Colorpicker`, `Keybind`, and `Paragraph`. See the individual element pages for their configuration options.
