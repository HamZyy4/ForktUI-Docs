## Loader example

The raw loader below tracks the latest `dist/main.lua` build on the `main` branch.

```luau
local ForktUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/HamZyy4/ForktUI/main/dist/main.lua"
))()
```

Copy the example as-is, then create a window:

```luau
local Window = ForktUI:CreateWindow({
    Title = "My Interface",
    Author = "sukitovone",
    Theme = "Dark",
    ToggleKey = Enum.KeyCode.RightShift,
})

local MainTab = Window:Tab({ Title = "General", Icon = "house" })
MainTab:Button({
    Title = "Test ForktUI",
    Callback = function()
        print("ForktUI is ready")
    end,
})
```

## Source revision and release stability

The `main` URL updates when the project publishes a new bundle. Pin a reviewed commit or release asset when a project needs a fixed version. The bundle should only be used after its GitHub Actions build has completed successfully.

## Roblox Studio installation

A normal Roblox Studio experience should use the ModuleScript workflow instead of a remote `loadstring` loader. Clone the repository with its icon submodule, build or serve it with Rojo, place the `ForktUI` ModuleScript in `ReplicatedStorage`, then require it from a client-side `LocalScript`:

```luau
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ForktUI = require(ReplicatedStorage:WaitForChild("ForktUI"):WaitForChild("Init"))
```

## Runtime notes

- The loader requires a client runtime with `loadstring` and HTTP retrieval support.
- Create and update the UI from a client context.
- Filesystem-backed config persistence and clipboard actions are optional runtime capabilities; ForktUI checks for their availability.
- The raw `main` URL is convenient for development. Use a pinned source revision for repeatable distribution.
