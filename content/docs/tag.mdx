---
title: Tag
description: Add compact status labels to the window header.
icon: Tags
---

Add a tag to the window to show a version, state, or other small piece of metadata:

```luau
Window:Tag({
    Title = "Stable",
    Color = Color3.fromHex("#a1a1aa"),
})
```

Use brief labels and restrained colors so tags remain secondary to the window title.
